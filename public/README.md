# Mídias do site

As imagens, SVGs e vídeos oficiais são carregados diretamente do Cloudinary, conforme os public IDs definidos em `src/config/media.ts`. Não é necessário copiar esses arquivos para esta pasta nem incluí-los no GitHub.

Mantenha os nomes dos public IDs no Cloudinary exatamente iguais aos definidos no mapa de mídias. Consulte o guia [`GUIA-DE-MIDIAS-SEMOVI.md`](../GUIA-DE-MIDIAS-SEMOVI.md), na raiz do projeto, para a lista completa e os formatos recomendados.
